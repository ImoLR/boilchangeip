# v2.2.23 — 新增 Tcscloud Seednet Provider（每日 04:00 换 IP）

用户 2026-11-25 批准设计（「按你推荐来做」）。目标：把 Tcscloud Seednet VPS（FLVX node 57，
`tcsseednet.imgamer.top`）接入 boil，和其他 VPS 一样每天 04:00 自动换 IP，并支持 TG 手动换 IP / 查 IP。

## 设计

- 新 Provider `tcscloud_seednet`，配置块 `tcscloud_seednet`：`ssh_host` / `ssh_port` / `ssh_user` /
  `ssh_key_path` / `known_hosts_path`（必填，绝对路径）/ `host_key_alias`（可选，默认 `ssh_host`）。
- 厂商 API 只能在 VPS 内访问：`http://ipapi.tcscloud.net:8002/getip`、`/changeip`，命令为固定常量，
  不接受配置注入。
- get_ip：一次 SSH 内同时取厂商 getip JSON 与公网出口（ipify / icanhazip）。厂商 `ip` 为空 = 切换中
  （不算错误，返回「切换中」）；两者都有且不一致 = 切换中；厂商接口不可用时退回公网出口 IP。
- change：IP 一变 SSH 会断，所以在节点上用 `setsid nohup` 分离启动 changeip（结果写
  `/tmp/boil-tcs-change.json`，`flock` 防并发），SSH 立即返回。
- 确认：等 30 s，然后每 10 s SSH getip，最长 300 s。成功 = 非空、合法公网 IPv4、≠ 旧 IP。窗口内
  任何 SSH 失败 / 主机密钥不匹配 / 切换中都继续轮询。
- 第二轮：最多 2 轮（硬上限）。只有窗口结束时最后一次成功查询到的仍是旧 IP（机器可达、确实没换）
  才发起第二轮；不可达 / 未知不重换（避免 DNS 慢时重复换 IP 断用户连接）。启动时主机密钥不匹配 =
  确定没执行，直接失败。
- 主机密钥固定：专用 known_hosts、`StrictHostKeyChecking=yes`、`HostKeyAlias`、`BatchMode`、
  `GlobalKnownHostsFile=/dev/null`、`UpdateHostKeys=no`。旧 IP 几分钟内会分给别的客户，DNS 未更新时
  SSH 会连到陌生机器，主机密钥不匹配只视为「尚未就绪」。Fachost 保持 accept-new 不改。
- 全局 `CHANGE_IP_LOCK` 只在发起换 IP 时持有（同 PQS），确认窗口内不阻塞其他服务器；服务器锁全程持有。
- 定时：由 `BOIL_GLOBAL_TIMER` `0 4 * * *` 覆盖（逐台顺序执行，新服务器放在 BOIL_SERVERS 末尾）。
